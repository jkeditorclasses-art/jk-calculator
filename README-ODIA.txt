JK Fertilizer Calculator – Android APK project

ଏହା ଏକ Android Studio / GitHub Actions project।
APK ଏଠାରେ ସିଧା compile ହୋଇନାହିଁ; GitHub Actions ଦ୍ୱାରା build କରିବାକୁ ପଡିବ।

Build:
1. ଏହି ZIP କୁ GitHub ରେ ନୂଆ repository ଭାବେ upload କରନ୍ତୁ।
2. Repository ର Actions tab ଖୋଲନ୍ତୁ।
3. "Build Android APK" workflow କୁ Run workflow କରନ୍ତୁ।
4. Build ସଫଳ ହେଲେ Artifacts ରୁ JK-Fertilizer-Calculator-APK ଡାଉନଲୋଡ୍ କରନ୍ତୁ।
5. ZIP ଭିତରୁ app-debug.apk ଖୋଲି Android ରେ install କରନ୍ତୁ।

Default rate ₹49/kg. Rate ଆପଣ app ଭିତରେ ବଦଳାଇପାରିବେ।
