Build APK on GitHub using a phone
1. Create a new GitHub repository.
2. Upload the contents of this ZIP (not the ZIP itself) to the repository root.
3. Open the repository's Actions tab.
4. Select "Build JK Calculator APK" and press "Run workflow".
5. When it completes, open the workflow run and download the "JK-Calculator-APK" artifact.
6. Extract the downloaded artifact ZIP; install app-debug.apk on Android.

This ZIP is the complete source project and build workflow; an APK binary has not been compiled in this environment.
